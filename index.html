Height Measure Machine

I have developed an Arduino UNO–based Smart Height Measurement Machine that determines an object's height without physical contact using trigonometric calculations and an ultrasonic sensor (HC-SR04). The system is controlled via an Android app and compensates for temperature effects on sound velocity for accuracy.

More about Project →

Cyclic Redundancy Check Simulator

This project was developed under the course CSE 3252: Computer Network Security (Sessional). We created a CRC simulator that transmits and receives binary data. If no error occurs, the receiver shows a syndrome of 000; otherwise, a different syndrome indicates an error.

About Me

Proshenjit Sarker has completed his Bachelor of Science in Electronics and Communication Engineering from Khulna University, Khulna, Bangladesh, and is currently pursuing his Master of Science degree in the same discipline at the same institution. His academic and research interests span machine learning, classification techniques, metaheuristic algorithms, and SHAP (Shapley Additive Explanations) analysis. He is particularly focused on applying these methods to healthcare data analytics and predictive modeling to develop efficient and interpretable machine learning solutions for real-world problems.
